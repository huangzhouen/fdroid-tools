# 博客模板 - 中文版

一个功能完整的中文 Blogger 模板，支持联网搜索。

## 简介

专为中文用户设计的 Blogger 模板，具有以下特色：

- 响应式设计 - 完美支持手机、平板和桌面设备
- 联网搜索 - 集成 Google 自定义搜索引擎 (CSE)
- 简洁美观 - 现代化的设计风格
- 易于定制 - 清晰的代码结构

## 功能特性

### 核心功能
- 文章列表展示
- 标签分类系统
- 文章归档
- 分页导航
- 移动端菜单

### 搜索功能
- 博客内搜索（Blogger 原生）
- 全网搜索（Google CSE）
- 搜索结果高亮

## 使用方法

1. 登录 Blogger 后台
2. 进入「主题」→「编辑 HTML」
3. 粘贴 `template.xml` 内容
4. 替换 `YOUR_CSE_ID_HERE` 为你的搜索引擎 ID
